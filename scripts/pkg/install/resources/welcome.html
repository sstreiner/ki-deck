ki-deck

See what every Kiro session is doing on your Stream Deck, approve or deny its actions, and jump to the one that needs you.

This installer:

  • puts the Kiro plugin into Stream Deck, for your user only, so no administrator password is needed;
  • quits Stream Deck while it copies the plugin and starts it again, so the keys go blank for a few seconds;
  • lets the plugin set up the Kiro side when it starts: kd-hook and the ki-deck command in ~/.ki-deck, Kiro's global hooks in ~/.kiro/hooks, and the Kiro companion extension;
  • puts the Kiro profile on your devices: Stream Deck asks once per device, then switches to it. Kiro profiles from an earlier version get this version's layouts; the old ones are backed up to ~/.ki-deck/backups, and keys you changed by hand in them are replaced too.

Nothing is gated, so Kiro keeps asking exactly as before. Undo it any time with Uninstall ki-deck, which this installer puts into the Applications folder in your home folder, or with ki-deck uninstall in Terminal.

You need the Stream Deck app 7.6 or later, and Kiro IDE or kiro-cli.
