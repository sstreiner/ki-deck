Almost there

Stream Deck is starting the plugin. A notification says when it has set up the Kiro side.

  1. Open a new chat in Kiro (and restart any kiro-cli session), and reload Kiro windows that were already open.
  2. When Stream Deck asks whether to install the Kiro profile for a device, confirm. No question? Run ki-deck profiles in Terminal, or drag the keys from the "ki-deck" category in the Stream Deck app. If Stream Deck says it "detected an error restoring the last session", choose Cancel.
  3. Check everything with ki-deck doctor.

Stream Deck not installed yet? Install it from elgato.com/downloads and start it: the plugin sets up the Kiro side then.

To remove everything later, open Uninstall ki-deck in your Applications folder (Finder: Go, Home, Applications), or run ki-deck uninstall.
